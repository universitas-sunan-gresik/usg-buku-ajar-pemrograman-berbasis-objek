# Dokumen Acuan

Folder ini berisi dokumen rujukan yang dipakai menyusun aturan penulisan.
Dokumen di sini **tidak diubah** dan bukan bagian dari naskah buku.

| Berkas | Peran |
|---|---|
| `RPS-Pemrograman-Berorientasi-Objek-OBE.pdf` | Sumber tunggal CPL, CPMK, Sub-CPMK, bahan kajian, matriks mingguan, rancangan tugas, bobot asesmen, dan rubrik R1 sampai R14. Menentukan **isi**. |
| `Contoh-Format-Buku-Ajar.pdf` | Contoh buku ajar terbitan Universitas Sunan Gresik. Dipakai **hanya sebagai acuan format**: ukuran halaman, font, urutan blok tiap bab, dan komponen front/back matter. Substansinya tidak dipakai. |

Bila kedua dokumen berselisih: RPS menang untuk isi dan capaian, contoh buku ajar menang untuk format dan struktur.
